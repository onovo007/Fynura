# Technology stack

Python, FastAPI, Pydantic, JavaScript, HTML, CSS, Google ADK, Google GenAI SDK, Gemini, Vertex AI, Cloud Run, Firestore, Cloud Scheduler, Secret Manager, Firebase Authentication, Leaflet, OpenStreetMap and Docker.

## Core responsibilities

- **Python and FastAPI:** APIs, typed evidence processing and application serving.
- **Google ADK and Gemini 3.7 Flash:** on-demand research and source review on Vertex AI.
- **Firestore:** evidence snapshots and application state.
- **Cloud Scheduler:** authenticated refresh checks.
- **Firebase Authentication:** Google sign-in and session verification.
- **Leaflet and OpenStreetMap:** geographic exploration with attribution.
- **Cloud Build, Artifact Registry and Cloud Run:** build, image storage and hosting.
- **HTTPX, Beautiful Soup and openpyxl:** retrieval and source parsing.

See [architecture](ARCHITECTURE_EXPLANATION.md) for the distinction between deterministic surveillance processing and model-assisted research.
