# Technical implementation summary

| Capability | Implementation |
|---|---|
| Generative model | Gemini 3.7 Flash through Vertex AI |
| Agent framework | Google ADK research agent and conditional source-review agent |
| Cloud infrastructure | Cloud Run, Firestore, Firebase Authentication and supporting Google Cloud services |
| Evidence processing | Deterministic parsing, compatibility checks and guarded calculations |
| User interaction | Source-linked questions, conversational follow-ups, charts and exports |

The [project story](DEVPOST_PROJECT_DETAILS.md), [architecture](ARCHITECTURE_EXPLANATION.md) and [testing guide](TESTING_INSTRUCTIONS.md) describe the implemented scope. Technical functionality does not establish clinical validation or operational outbreak-prediction capability.
