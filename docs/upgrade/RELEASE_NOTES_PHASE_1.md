# Phase 1 foundation release notes

## Added

- NCDC weekly-report registry record with validation status and source-access metadata.
- Additive provenance, epidemiological interval, revision and QA fields on observations.
- Reviewed normalized-table adapter and official-report regression fixture.
- Nigeria state/FCT crosswalk and explicit LGA ambiguity gate.
- Nigeria availability API and public status cards.
- Phase 0 audit, source access matrix, data dictionary, implementation gate, privacy review and handover instructions.

## Preserved

- Existing WHO adapters and verified observations.
- Existing routes, authentication, data refresh, Ask Fynura, source explorer, maps, history, branding and deployment configuration.

## Not activated

- Automatic NCDC document retrieval, production storage and scheduled refresh.
- Subnational case maps or counts.
- News, mobility, forecasting or operational prioritization.

These items remain gated by the staged plan and must not be presented as operational.
