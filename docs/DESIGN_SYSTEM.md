# Fynura design system

Fynura uses warm off-white surfaces, deep green-black typography, restrained signal colors and compact source metadata. Large numerical values, consistent spacing and contextual actions make evidence easier to inspect.

Color is paired with labels and symbols. Charts provide accessible tables and source links. Motion is restrained and respects reduced-motion preferences.

The interface uses FastAPI-served HTML, CSS and JavaScript. Deterministic APIs provide surveillance values; research responses are presented separately with their supporting sources.
